# 📊 HR Analytics Dashboard

An interactive Power BI dashboard designed to analyze employee attrition, workforce demographics, job roles, job satisfaction, and other key HR metrics.

This project demonstrates the use of Power BI, Power Query, DAX, and data modeling to transform HR data into actionable business insights.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key Objectives

- Analyze employee attrition patterns
- Understand workforce demographics
- Evaluate employee satisfaction metrics
- Explore department-wise performance trends
- Generate actionable HR insights
